Поэтому скриншот `accessibility-index.png` относится к варианту непосредственно перед последней текстовой правкой. Для строгого подтверждения результата именно последней редакции полезно переснять Lighthouse для главной страницы.

Сами изображения оставлены без изменения и без подделки результатов. Проверка 100/100 не доказывает автоматом полное соответствие всем требованиям A11y — предусмотрена ручная проверка `Tab`, `Enter`, `Escape`, ссылок, форм и модальных окон.
