# Фотографии и адаптивные размеры для КР №3

На сайте используются **две** исходные фотографии (портретов пилотов нет).
Для каждой создано **ровно три размера**, без увеличения сверх оригинала.

| Фото | 1-й размер | 2-й размер | 3-й размер | Где используется |
|---|---|---|---|---|
| Фон F1 | `hero-bg-480.jpg` | `hero-bg-800.jpg` | `hero-bg-1308.jpg` | `css/responsive.css` через media queries |
| Red Bull RB22 | `redbull-480.jpg` | `redbull-640.jpg` | `redbull-739.jpg` | `product.html` через `img[srcset]` |
| Red Bull RB22, WebP | `redbull-480.webp` | `redbull-640.webp` | `redbull-739.webp` | `product.html` через `picture > source[srcset]` |

Файлы `hero-bg.jpg` и `redbull.jpg` оставлены как исходники для будущих правок.
Меньшая фотография Red Bull исходно 739 пикселей, её **не растягивали** до 960/1200.

**Как проверить выбор файла:** DevTools → Network → Img, затем обновить `product.html` на разных ширинах. У `img` в Elements можно посмотреть `currentSrc`. Включите **Disable cache** при повторном сравнении и помните, что экран с высокой плотностью пикселей может выбрать более крупный файл даже на телефоне.
