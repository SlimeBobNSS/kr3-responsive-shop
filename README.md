**Студент:** Голованов Макар Денисович  
**Группа:** ЭФБО-04-25  
**Тема:** Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта.  
**Основа:** F1 Hub из КР №1. **Bootstrap не используется.**

## Состав проекта

Пять страниц: главная `index.html`, каталог пилотов `catalog.html`, техническая страница болида RB22 `product.html`, учебная заявка на гонку `order.html`, контакты `contacts.html`.

## Практическое занятие №12 — адаптивность

- `css/responsive.css` подключён после основного `css/style.css` на всех страницах.
- `viewport`, Mobile First, медиазапросы, CSS Grid и Flexbox.
- Адаптированы навигация, hero, карточки пилотов, фильтры, формы, модальное окно и футер.
- Изображение болида RB22 — WebP/JPEG, `picture`, `srcset` и `sizes`; изображения гибкие.
- Таблица характеристик RB22 на мобильном устройстве преобразуется в карточки.
- Выбор и сортировка пилотов работает через HTML `data-*` и JS; Bootstrap не используется.


## Изображения для разных экранов

На сайте две фотографии: фон главной страницы и болид Red Bull RB22. Для **каждой фотографии созданы три реальных размера**:

- Фон: 480, 800, 1308 px — выбор JPG через медиазапросы в `responsive.css`.
- Болид: 480, 640, 739 px — каждый размер в JPG и WebP; `<picture>`, `srcset`, `sizes` на странице `product.html`.
- Фотографии гонщиков в каталоге **отсутствуют**, как в исходной версии сайта.
- Все версии и инструкция по DevTools — `images/SIZES.md`.

## Практическое занятие №13 — доступность

- Ссылка пропуска к контенту `skip-link`.
- Видимый клавиатурный фокус `:focus-visible`.
- `aria-current` для текущей страницы, `aria-label` для навигации.
- Связанные `label`, осмысленные `alt`, статусные сообщения `role=status`.
- Высота модального окна ограничена, возможна прокрутка внутри него.
- В `lighthouse/` помещены пять реальных скриншотов проверки Lighthouse Accessibility (100/100 на каждой странице).

## Источники и ограничения

См. `DATA_SOURCES.md`. Сайт создан для учёбы, не является официальным сервисом Формулы-1 и не осуществляет продажу билетов.

### Каталог пилотов и изображение RB22

- В каталоге представлены 22 действующих пилота; номера 1–22 обозначают порядок **среди действующих пилотов**, а не номера строк полной официальной классификации (в ней могут присутствовать пилоты, не входящие в текущий состав).
- Исходное изображение RB22 имеет размер 739×415 px. Для сохранения качества на desktop его отображение ограничено 620 px по ширине; `srcset` и `sizes` оставлены для выбора файлов браузером. Увеличить исходную детализацию без изображения более высокого разрешения невозможно.
